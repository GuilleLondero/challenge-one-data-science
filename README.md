# challenge-one-data-science

# 📊 Análisis de Ventas de Tiendas

Este proyecto tiene como objetivo analizar los datos de ventas de cuatro tiendas del Sr. Juan con el fin de tomar una decisión informada sobre cuál de ellas vender. A través de un análisis exhaustivo, se estudian múltiples factores como facturación, satisfacción de clientes, productos más/menos vendidos, distribución geográfica y más.

---

## 📁 Estructura del Proyecto

- `notebook.ipynb`: Contiene todo el análisis de datos, visualizaciones y conclusiones.
- `datasets/`: Carpeta con los archivos CSV vinculados a cada tienda.
- `README.md`: Documento explicativo del proyecto.
